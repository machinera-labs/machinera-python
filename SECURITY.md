# Security policy

## Supported versions

| Version | Security fixes |
| --- | --- |
| Latest published release | Supported |
| Older releases | Upgrade to the latest release |
| Development snapshots and prereleases | No support commitment |

This policy takes effect with the first published release. It does not promise
long-term support or a fixed grace period. Supported Python versions are listed
in the [README](README.md#versioning-and-requirements).

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/machinera-labs/machinera-python/security/advisories/new)
as the only reporting route.
Do not disclose security issues in public issues or pull requests.

Include affected SDK and Python versions, a minimal reproduction with synthetic
inputs, the potential impact, and a way to contact you. Do not send API keys,
private audio, transcripts, or signed URLs. Coordinate public disclosure with the
maintainers while a fix is prepared.
